# Frontend Testing Rules

- 工具函数和状态逻辑覆盖主流程、边界值和错误分支。
- 组件测试关注用户可观察行为，不依赖内部实现细节。
- 页面测试覆盖加载、空数据、失败、权限不足、重复提交和取消场景。
- 关键跨端流程使用集成测试或 E2E 测试覆盖，但不得用大量脆弱 E2E 代替单元测试。
- Mock API 边界，不 Mock 被测组件自身的业务逻辑。
- 涉及异步请求时验证 loading、错误恢复、取消和竞态处理。
- Bug 修复必须增加能在修复前失败、修复后通过的回归测试。
- 完成后按项目实际脚本执行 format-check、lint、typecheck、test 和 build。
