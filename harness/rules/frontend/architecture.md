# Frontend Architecture Rules

- 编码前先确认实际框架、路由、状态管理、组件库、请求层和目录约定。
- 页面负责用例组合，复杂业务逻辑下沉到 composable、hook、store 或 service。
- 通用组件不得依赖具体业务页面；业务组件不得绕过统一请求层和错误处理。
- 全局状态只保存真正跨页面共享且需要生命周期管理的数据，避免把局部状态全部提升。
- 路由、权限、菜单和页签策略必须复用项目现有实现，不在单个页面创建平行机制。
- API 调用通过统一 Client 或 service 层，复用认证、超时、取消、错误映射和追踪信息。
- 大型页面按路由或功能拆分，评估懒加载、资源体积和重复请求。
