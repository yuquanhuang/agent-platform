# Frontend Design System Rules

- 视觉规范的项目级来源为 `harness/project/design-system.md`。
- 颜色、字体、字号、间距、圆角、阴影、层级和布局尺寸优先使用设计 token。
- 业务组件中不得散落新的颜色值和重复视觉常量；缺失 token 时先更新设计系统。
- 优先使用项目组件库和已有复合组件，避免为单个页面复制相似实现。
- 新页面同时检查桌面端、窄屏、文本溢出、加载、空数据、错误和禁用状态。
- 可交互元素必须具备键盘可达性、可见焦点和可理解的辅助文本。
- 修改全局 token、主题或基础组件时必须评估全站影响并进行视觉回归检查。
