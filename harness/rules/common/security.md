# Common Security Rules

- 所有来自浏览器、API、文件、消息和外部服务的数据默认不可信。
- 身份认证和权限校验必须在访问数据或执行副作用之前完成。
- 前端隐藏按钮不等于权限控制，最终授权由服务端负责。
- 凭证只从环境变量、配置中心或密钥系统读取，不进入源码和日志。
- 日志不得输出密码、Token、Cookie、Authorization Header 或完整敏感数据。
- 文件名、路径、URL 和对象存储 Key 必须防止目录穿越、非法协议和越权访问。
- 动态执行、反序列化、模板渲染、文件解析和第三方内容展示必须专项评估风险。
- 新增依赖前检查维护状态和安全影响，发现漏洞时明确升级与兼容策略。
